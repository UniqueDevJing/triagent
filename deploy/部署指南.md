# 传智健康管理系统 - 部署指南

## 服务器要求

| 项目 | 最低配置 | 推荐配置 |
|------|----------|----------|
| CPU | 1核 | 2核 |
| 内存 | 2GB | 4GB |
| 系统 | Ubuntu 20.04+ / CentOS 7+ |
| 磁盘 | 20GB | 40GB+ |

> 2GB 内存只能跑 Docker 方式。1GB 服务器只能用外部 MySQL+Redis，或换 H2 内嵌数据库。

---

## 方式一：Docker Compose（推荐，2GB+ 服务器）

### 1. 上传文件

将整个 `deploy/` 目录上传到服务器：

```bash
# 在本地执行（替换为你的服务器IP）
scp -r deploy/ root@你的服务器IP:/opt/health/
```

### 2. 配置密钥

```bash
ssh root@你的服务器IP
cd /opt/health/deploy/

# 创建 .env
cp .env.example .env
nano .env   # 填入真实密码和密钥
```

### 3. 一键启动

```bash
chmod +x deploy.sh
./deploy.sh
```

### 4. 访问

```
http://服务器IP          # 前端页面
http://服务器IP:8080     # API (Knife4j文档)
```

## 方式二：手动部署（1GB 服务器）

### 1. 安装依赖

```bash
# MySQL (或使用云数据库)
apt-get install -y mysql-server
# Redis
apt-get install -y redis-server
# Java 17
apt-get install -y openjdk-17-jre-headless
# Nginx
apt-get install -y nginx
```

### 2. 初始化数据库

```bash
mysql -u root -p < init.sql
```

### 3. 启动后端

```bash
# 限制内存
java -Xms64m -Xmx256m -jar health-server-v3.jar \
  --spring.profiles.active=prod \
  --DB_PASSWORD=你的密码 \
  --JWT_SECRET=你的JWT密钥 \
  --AI_API_KEY=你的AI密钥 \
  --REDIS_HOST=localhost \
  --DB_HOST=localhost &
```

### 4. 配置 Nginx

```bash
cp nginx.conf /etc/nginx/conf.d/health.conf
# 修改 proxy_pass 中的 backend 为 localhost
sed -i 's/backend/localhost/g' /etc/nginx/conf.d/health.conf
systemctl reload nginx
cp -r dist/* /usr/share/nginx/html/
```

## 演示模式（T8 安全化）

公网演示环境建议开启只读演示账号模式，在 .env 中设置 `TRIAGENT_DEMO_ENABLED=true`
（deploy/docker-compose.yml 已默认开启），并初始化演示账号：

```bash
mysql -u root -p health_management < sql/demo_account.sql   # 创建 visitor 只读账号
```

开启后效果：

- `visitor` 为只读账号：所有 GET 正常放行；POST/PUT/DELETE 仅放行
  `/api/v1/assistant/chat`（演示对话）与 `/api/v1/logout`，
  其余管理操作一律 403 并记录拦截日志。
- `visitor` 每日聊天上限 20 次（`triagent.demo.daily-chat-limit` 可调），超出返回 429，次日自动恢复。
- 非 visitor 账号不受任何影响，本地开发默认 `enabled=false` 关闭该模式。

演示数据重置（清空 visitor 产生的预订单与评估记录）：

```bash
mysql -u root -p health_management < scripts/reset_demo_data.sql
docker compose restart backend   # 可选：一并清空内存会话轨迹与幂等缓存
```

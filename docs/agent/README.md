# docs/agent · 智能分诊系统文档索引

本目录记录系统的设计、评估与质检全过程。**评估类文档存在三个版本**，数字口径不同，
下表说明各自的定位与引用场景，避免混淆。

## 评估文档版本关系

| 文档 | 样本量 | 裁判方式 | 定位 |
|---|---|---|---|
| [评估报告.md](./评估报告.md) | 10 例（G1–G10） | 规则比对 | 最早基线（09-02），记录 v2 版JSON 重试修复 |
| [测试数据报告.md](./测试数据报告.md) | 10 例（G1–G10） | 规则比对 | 二次基线（09-06 凌晨），含逐例耗时与 token 事件 |
| **[评估报告-LLM裁判.md](./评估报告-LLM裁判.md)** | **30 例**（29 分诊 + 1 路由） | **规则裁判 + LLM-as-Judge** | ✅ **当前权威结论** |

三份文档的差异来自**评估集扩容与裁判方式升级**，不是结论冲突。
对外引用请以 30 例版本为准，并注明样本量。

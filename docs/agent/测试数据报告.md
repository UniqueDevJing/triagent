## 6. 已知局限

1. G4（呼吸困难）与 G6（本胆反流型上腹痛）实际判得比 golden **更紧一档**（EMERGENCY/URGENT）——方向为安全从严，按 0.5 计分。
2. LLM 路径延迟受第三方 API 波动影响（3.9–6.2s），确定性路径不受影响。
3. 稳定性子项以「科室命中 5/5 + 评分无回退」替代重复计时（避免同会话状态机残留干扰计时）。
